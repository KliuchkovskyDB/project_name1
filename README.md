# Прогнозирование стоимости подержанных автомобилей (Car Price Prediction)

Данный репозиторий содержит материалы лабораторных работ по курсу «Интеллектуальные информационные системы». 

---

## 1. Описание проекта

* **Тип задачи:** Регрессия (Machine Learning).
* **Цель:** Разработать модель машинного обучения для оценки и прогнозирования рыночной стоимости подержанного автомобиля (`Selling_Price`) на основе его технических характеристик, возраста, пробега и истории эксплуатации.
* **Используемый датасет:** Car Price Prediction ([Kaggle](https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars)).
* **Целевая переменная:** `Selling_Price` — цена продажи автомобиля на вторичном рынке (в лакхах индийских рупий, 1 лакх = 100 000 рупий).

### Основные признаки:
* `Car_Name` — марка и модель автомобиля;
* `Year` — год выпуска;
* `Present_Price` — розничная цена аналогичного нового автомобиля из автосалона (в лакхах);
* `Driven_kms` / `Kms_Driven` — фактический пробег автомобиля в километрах;
* `Fuel_Type` — тип топлива (`Petrol`, `Diesel`, `CNG`);
* `Selling_type` / `Seller_Type` — продавец (`Dealer` — автодилер, `Individual` — частное лицо);
* `Transmission` — тип коробки передач (`Manual` — механика, `Automatic` — автомат);
* `Owner` — количество предыдущих владельцев (0, 1, 3).
